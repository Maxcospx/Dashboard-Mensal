Para um trabalho universitario, foi requisitado que os alunos da matéria Engenharia de Prompt, que fizessem um 
site gerado por AI, que fizesse atividades simples de acordo com a criatividade dos alunos, nisso fiz um site cooperativo com a copilot
que ajuda o usuario a conseguir gerir toda as atividades finaceiras com o seguinte prompt.

PROMPT: Crie um dashboard financeiro moderno, responsivo e de fácil navegação usando apenas HTML Puro (sem frameworks ou bibliotecas externas). O objetivo é entregar uma interface limpa, intuitiva e profissional para controle financeiro pessoal ou empresarial.

Aonde a copilot me gerou o seuinte codigo registrado em INDEX.HTML. 

O site teve um excelente resultado, mais ainda pode ser melhorado para facilitar a aquisicao de arquivos e busca de dados.
